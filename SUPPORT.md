# Support

Hermes Jack-In is maintained on a best-effort basis.

- Search existing issues before opening a sanitized bug report.
- Include the released version, operating system, Python version, command exit
  status, and a minimal reproduction using temporary trees.
- Do not publish credentials, personal paths, private skill text, manifests from
  a live destination, or vulnerability details.
- Feature requests should explain the source/destination contract and expected
  safety boundary; requests that weaken ownership or fail-closed behavior will
  not be accepted.
- Use the process in `SECURITY.md` for suspected vulnerabilities.

Only the latest released version and platforms with a passing native release
matrix are supported. General Hermes Agent and Claude Code questions belong in
their respective upstream support channels.
